# 정리 프롬프트 규칙

학습노트 본문 마크업(`[[ ]]` · `[ ]` · 루비)에 맞춰 글을 받아오기 위한 프롬프트다.
아래 블록을 통째로 복사해 쓰고, 마지막 줄의 `(주제)` 자리에 주제를 적는다.

마크업 구현은 `lib/ruby.ts` 와 `components/RubyText.tsx` 에 있다. 규칙을 고칠 때는
파서와 어긋나지 않는지 함께 확인한다.

## 프롬프트

```
아래 규칙에 맞춰서만 정리해줘. 규칙 밖의 머리말·맺음말·설명은 붙이지 마.

■ 공통
- 한자는 쓰지 않는다. 원어를 병기할 땐 영어(로마자)로만 적는다.
- 문체는 "~입니다"체로 쓴다.
- 세기·연도·숫자는 아라비아 숫자 그대로 쓴다. ("이십일세기"(X) → "21세기"(O))
- 대괄호와 중괄호는 아래 문법 용도로만 쓴다.

■ 출력 구조 (이 순서 고정)
1) [[제목{뜻,영어}]]  — 맨 앞에 한 줄, 딱 한 번
2) 주제 전체를 1~2문장으로 요약한 문단 — 한 문단
3) [흐름도] — 한 줄
4) 항목 설명 4~6개 — 각 항목은
   낱말{뜻,영어}: 한 문장 설명
   예 : 유명한 사례 (있을 때만, 없으면 생략)
5) 연관 : 함께 알아두면 좋은 용어 3~5개를 가운뎃점으로 이어 한 줄 (맨 마지막)
6) 혼동 : 서로 헷갈리기 쉬운 용어 쌍이 있을 때만 한 줄 (없으면 생략)

■ 정렬 규칙 (중요도 순)
- 항목 설명은 중요도가 높은 것부터 내림차순으로 쓴다.
- 중요도 판단 기준은 이 순서로 적용한다.
  1순위 : 이 낱말을 모르면 주제 자체를 이해할 수 없는 것
  2순위 : 시험·설명·인용에서 반복해서 등장하는 것
  3순위 : 알아두면 이해가 깊어지지만 없어도 되는 것
- 단, 흐름·변천이 있는 주제는 흐름도와 항목 설명의 순서를 일치시켜 시간 순으로 쓴다.
  (흐름도는 시간 순인데 항목만 중요도 순이면 대응이 어긋나 읽기 어렵다)
  이때 가장 중요한 항목은 설명을 한 문장 더 붙여 비중을 드러낸다.
- 연관 용어 줄도 중요도가 높은 것부터 쓴다.

■ 문법
[[ ]] : 제목. 줄 전체를 감싼다. 굵고 강조색으로 보인다.
[ ]  : 흐름도 한 줄을 감싼다. 제목보다 한 단계 약한 강조로 보인다.
       흐름·변천 순서가 있는 주제 → 화살표로 잇는다.
         예: [선사-미술{주술·다산} → 이집트-미술{영생·내세}]
       순서가 없는 주제 → 핵심 축을 중요도 순으로 가운뎃점으로 잇는다.
         예: [정의{개념·범위} · 구조{요소·관계} · 의의{영향·한계}]
       대괄호 안에 대괄호를 또 넣지 않는다.
낱말{ } : 루비. 낱말 바로 뒤에 공백 없이 붙이면 그 낱말 위에 작은 글씨로 뜻·원어가 뜬다.
       - 뜻을 여러 개 나란히 달 땐 콤마: {뜻,영어}
       - 한 뜻 안에서 대등한 말을 묶을 땐 가운뎃점: {주술·다산}
       - { } 안에 "^" 를 쓰지 않는다 (각주 번호 문법과 겹친다)

■ 하이픈 규칙
- { } 바로 앞에 오는 낱말(루비가 붙는 낱말)에만, 공백 대신 "-"를 쓴다.
  예: 21세기-미술-사조{...}, 헌법-개정{...}
- { } 안의 내용에는 하이픈을 쓰지 않는다. 뜻과 원어는 평소대로 띄어쓴다.
  예: {시대 사조,Contemporary Art}   /   {디지털 기술 융합 예술,Media Art}
- 루비가 붙지 않는 일반 서술 문장은 평소대로 띄어쓴다.
- 화면에는 "-"가 다시 빈칸으로 보이므로, 루비가 붙는 낱말에는 공백을 절대 쓰지 않는다.

■ 예시
[[21세기-현대-미술-흐름{시대 사조,Contemporary Art}]]

21세기 현대 미술은 기술과 생태, 관객 참여 중심의 다원주의 예술로 발전하고 있습니다.

[설치미술{공간·체험} → 미디어아트{디지털·영상} → 관계미학{참여·소통} → 생태미술{환경·생명} → 인공지능-아트{가상·생성}]

미디어아트{디지털 기술 융합 예술,Media Art}: 현대 디지털 기술 매체를 표현의 중심 도구로 삼아 시공간의 경계를 확장한 예술입니다. 21세기 현대 미술을 관통하는 가장 큰 축으로, 이후의 거의 모든 사조가 이 매체 위에서 전개됩니다.
예 : 백남준의 비디오 아트와 팀랩의 몰입형 인터랙티브 디지털 전시

관계미학{참여와 소통의 미학,Relational Aesthetics}: 작품을 완성된 사물이 아니라 관객 사이에서 일어나는 만남과 관계 자체로 보는 관점입니다.
예 : 리크리트 티라바니자의 관객에게 음식을 나누는 전시

연관 : 포스트모더니즘{탈근대 사조,Postmodernism} · 비엔날레{국제 미술 축제,Biennale} · 큐레이팅{전시 기획,Curating} · NFT-아트{블록체인 기반 디지털 소유,NFT Art}

혼동 : 미디어아트{매체 중심}와 뉴미디어아트{기술 신생성 중심}는 겹치지만 강조점이 다릅니다

---
이제 위 규칙대로 아래 주제를 정리해줘:
(주제)
```

## 규칙이 이렇게 정해진 이유

- **하이픈은 루비가 붙는 낱말에만.** 파서가 `{` 바로 앞의 `/(\S+)$/` 하나만 베이스로
  잡는다(`lib/ruby.ts`). 공백이 있으면 마지막 한 낱말에만 루비가 얹힌다. 화면에서는
  `displayRubyWord()` 가 그 "-"를 NBSP 로 되돌려 다시 빈칸으로 보여준다.
- **{ } 안에는 하이픈을 쓰지 않는다.** NBSP 치환은 베이스 낱말에만 적용되고 루비
  내용에는 적용되지 않아, 하이픈이 화면에 그대로 남는다. 같은 이유로 `Post-Impressionism`
  처럼 원어에 원래 들어 있는 하이픈은 그대로 써도 안전하다.
- **`[ ]` 는 흐름도 전용.** 부분강조와 흐름도가 같은 기호를 쓰면 렌더러가 구분할 수
  없어 용도를 하나로 좁혔다. 파서가 대괄호 중첩을 받지 않는 것도 같은 제약이다.
- **`{ }` 안의 `^`.** `^` 뒤는 각주 번호로 읽히므로 루비 내용에 쓰면 글이 깨진다.
- **중요도 순 정렬.** 카드로 넘겨 보는 화면에서는 위에서부터 읽으므로, 앞에 온 것이
  곧 중요한 것이 된다. 흐름 주제만은 흐름도와 순서를 맞추는 편이 읽기 쉽다.
